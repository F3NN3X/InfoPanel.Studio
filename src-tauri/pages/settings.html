Coding agents

Shows Claude Code and Codex sessions on the dashboard. Turning this on edits ~/.claude/settings.json and ~/.codex/hooks.json (each backed up first): it adds hooks that run InfoPanel Studio's own Node, and wraps your Claude Code statusline so it keeps running and printing as before. Turning it off takes them out again.
