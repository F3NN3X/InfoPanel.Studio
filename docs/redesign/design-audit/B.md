# Design audit B: studio editing

Branch `design/full-audit`. Read-only static review; no dev server, no live data touched.

## Scope

Reviewed (`src/components/studio/`): `studio-canvas.tsx`, `placement-frame.tsx`, `placement-content.tsx`, `rulers.tsx`, `selection-chip.tsx`, `quick-bar.tsx`, `quick-sets.ts`, `status-bar.tsx`, `page-tabs.tsx`, `left-rail.tsx`, `phone-tab-bar.tsx`, `design-left-panel.tsx`, `layers-tree.tsx`, `layer-menu.tsx`, `layer-section.tsx`, `panel-layers.tsx`, `studio-inspector.tsx`, `floating-inspector.tsx`, `item-inspector.tsx`, `item-parts.tsx`, `group-inspector.tsx`, `page-inspector.tsx`, `zone-inspector*.tsx`, `inspector/*` (view, sheet-view, source-dot, island-section, data-picker, value-box), `setting-card/control/pickers/rows`, `settings-group/panel`, `section-inherit.tsx`, `inherit-chip.tsx`, `rename-input.tsx`, `align-grid.tsx`, `pane-sheet.tsx`, `bottom-sheet.tsx`, `explorer/*`. Shared primitives checked as sources: `src/index.css`, `src/components/ui/{icon-button,toggle,segmented}.tsx`. Tokens: contrast computed from the `--ui-*` hex values in `src/index.css:100-125` (node script, WCAG relative luminance). Fixtures `src/dev/fixtures/one-editor.ts` used as the map of the eight states; none rendered.

Excluded: Add, Library, Gauges, Screens, Import, first-run, alerts flows (reviewer C), widget internals.

Conventions found: `AGENTS.md`, `docs/TESTING.md`, `docs/design-overview.md`, `docs/architecture.md` (Edit section), `.impeccable/config.json` (only a lab-page ignore). Dense 11-13px dark chrome, terse British-ish copy and fixed `--ui-*` tokens are treated as deliberate. Skipped as taste: density, radii, voice.

Domain coverage: accessibility, layout, writing, typography, colors, ui all reviewed statically. Not verified (needs a render): ruler legibility at low zoom, tab order and focus order in the live inspector, forced-colors rendering, behaviour at 320px and 200% zoom, the `ContextMenu`/`Popover` primitives' own keyboard handling (`components/ui/context-menu.tsx`, `popover.tsx` not read).

Measured contrast (text on `--ui-bg-panel` #111114 unless noted): `--ui-text-5` #6f6f79 3.79 (3.60 on raised, 3.49 on hover); `--ui-text-4` #85858f 5.16; `#7c7c86` 4.56 (4.33 on raised); `#4a4a52` 2.15; `#5a5a63` on app 2.86; `--ui-border-default` vs panel 1.22; `--ui-border-strong` vs panel 1.32.

## Verification

Checked: contrast computed with a node script from the hex tokens above (exit 0). Grep passes for `outline-none`, `onClick` on non-buttons (none found), unlabeled icon-only buttons (one: `setting-card.tsx:90`, intentionally `aria-hidden`), text under 11px, `text-ui-5`, hard-coded colours, reduced-motion guards, forced-colors rules.

Not verified: any rendered behaviour (focus order, 320px and 200% zoom, ruler legibility at low zoom, forced-colors), the keyboard model of `ui/context-menu.tsx` and `ui/popover.tsx`, the eight Edit v3 fixture states visually.

Verdict: `Block` (6 HIGH). Remaining domains were all inspected statically; B-11, B-16, B-17 and B-21 need a render to confirm.
