# Design audit F: the cross-cutting design system

Branch `design/full-audit`. Read-only audit. Contrast figures were computed from the declared token values (WCAG 2 ratio, APCA Lc where useful), including alpha compositing and OKLCH to sRGB conversion. The script lives in the session scratchpad, not in the repo.

## Scope reviewed
- `src/index.css`, `src/select.css`, `src/select-scrollbar.css`, `src/settings/tokens.css`, `src/components/surfaces.ts`, `src/components/widget-style.ts`, `src/components/ui/*` (all 16 files), `src/lib/theme.ts` (6 built-in palettes), `theme-model.ts`, `style-resolve.ts`, `theme-apply.ts` (logic only, no colour values), `src/widgets/core/theme.ts` (`TEXT_VARS`, `STATE`, `TONES`), `widgets/core/surfaces.ts`, the 14 skins in `widgets/core/skins/`, and the 64 template palettes (`lib/screen-templates/designs/`) as the built-in themes.
- Measured: every `--ui-*` text/surface/status/border pair (185 pairs), `--color-s-*` settings pairs, `select.css` literals, 70 token sets (6 built-in plus 64 template palettes) x 16 pairs each, widget tones (`dark`/`light`/`theme`), glass/matte surfaces, `STATE`, skin accents on skin surfaces, focus-ring composites.
- Excluded: component-level layout of studio screens (other reviewers), per-widget internals, copy. Usage counts are greps over `src/`, so approximate.
- Not reviewed: rendered appearance (no dev server, so glass over real page backgrounds, forced-colors rendering and the live `appearance: base-select` list are inferred); better-writing (no copy in scope).
- Convention docs found: `AGENTS.md`, `docs/TESTING.md`, `docs/design-overview.md` (no token or contrast rules), `docs/architecture.md`, `.impeccable/config.json` (one lab-only ignore). No Storybook or interface ADRs.

## Export flag (InfoPanel output)
Studio chrome tokens (`--ui-*`, `--color-s-*`, `select.css`, `ThemeTokens` presets) are never written into an `.infopanel`; they are safe to change. These are not safe to change without a paired edit:
- `src/widgets/core/theme.ts:49-51,111,114` (`TEXT_VARS` dark fg/muted/track, `STATE` ok/warn/crit, default accent `#34d399`) are mirrored as fixed hex in `src/lib/infopanel/gauges/vector.ts:35-42` (`THEME`), which is baked into exported gauge frames.
- `src/lib/infopanel/editor/look.ts:10` `ACCENT = #FF3B82F6` and `elements/palette.ts` `defaultPalette` are written as plain InfoPanel colour fields.
F-02 and F-12 touch `--w-*` values; if they change `--w-fg`, `--w-muted`, `STATE` or the default accent, `vector.ts` must change with them or exported gauges drift from the live widget.
