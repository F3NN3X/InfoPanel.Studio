# Design audit D: desktop shell (app window chrome, Settings window, Help)

Branch `design/full-audit`. Static review, no dev server run. Contrast ratios are computed from the real token values in
`src/settings/tokens.css` (WCAG relative luminance; oklch tokens converted to linear sRGB).

## Scope reviewed
- `src/app-window/` (title-bar, search-box, kbd, zoom)
- `src/settings/`: shell, nav, ui, window, window-desktop, window-pages, app, store (load and toast), tokens.css, settings.css, window.css; sections `updates`, `changelog`, `about`, `general`, `diagnostics`, `logs`, `connections`; `server` (error callout, port and hosts inputs); `model/cards.ts` (update card states)
- `src/help/`: app, `ui/*` (sidebar, home, results, article, blocks, inline-text), env, main, help.css; articles `updates.md` and `shortcuts.md` sampled for copy
- Recon: AGENTS.md, docs/TESTING.md, docs/design-overview.md, Tauri window sizes (`src-tauri/src/windows.rs:471`, min 760x520), `.impeccable/config.json`

## Excluded / Not reviewed
- Studio editor and widgets (other reviewers). `docs/architecture.md` not read for this surface.
- `settings/sections/touch.tsx`, `agents.tsx`, most of `server.tsx`: read only by grep for shared patterns (inputs, dim/faint text), not line by line.
- `help/search.ts`, `check.ts`, `build.ts`, `parse.ts` (logic, no UI). The other 33 Help articles' copy.
- All six domains were reviewed. `inferred` rows need a rendered check in WebView2 (focus clipping, sticky-bar overlap, zoom reflow).
- Honoured as project taste: dark-only, dense 12.5-13.5px rows, terse copy, custom title bar.

## Verification
- Contrast computed in Node from `tokens.css` values: s-faint 2.30-2.65, s-dim 3.41-3.93, log timestamp 2.27, switch off 1.40, field border 1.32. Passed: s-muted 4.96-5.72, accent button text 7.79, restart bar 13.47, close-hover white on red 5.66, red text 6.5.
- Checked and fine: the global `:focus-visible` rule is unlayered, so it beats the layered Tailwind `outline-none` on the bare inputs (`settings.css:67`); icon buttons in the title bar and search have names; switches have `role=switch` and names; `Segmented` is a radiogroup with roving tabindex; nav uses `aria-current`; Help has a no-results state.
- Not verified (needs a rendered run): sticky-bar overlap (D-08), scroller focus (D-15), reflow at 150% zoom in a 760px window (D-18), release rail height (D-33).
