# Design audit A: the kiosk

Branch `design/full-audit`. Static review; no dev server was run. Contrast values were computed from the token values (WCAG relative luminance); a pair marked "bg assumed" uses a surface colour I could not read from one file.

## Scope reviewed

- `src/App.tsx` (kiosk route: load, pull, background, grid, dim, alerts, island, dots, touch layer, KioskStrip; the non-kiosk `ConnectionStatus` header and Wrench button for contrast with the kiosk)
- `src/components/`: `kiosk-strip.tsx`, `page-dots.tsx`, `page-background.tsx`, `pulse-dot.tsx`, `touch-layer.tsx`, `modern-chrome.tsx`, `zone-error-boundary.tsx`, `alerts/*`, `island/*`
- `src/touch-overlay/*` (setup overlays shown on touch displays)
- Widget shell: `src/widgets/core/Widget.tsx`, `theme.ts` (text vars), `views.tsx` (compact/studio summary views), `src/components/studio/placement-frame.tsx` (the kiosk branch and `NoLiveData`), `src/lib/sensor-store.ts` and `src/lib/island/system.ts` for the offline behaviour
- `src/index.css` (kiosk, alert, island rules). States covered: empty, loading, offline, error, narrow.
- Project docs read: `AGENTS.md`, `docs/TESTING.md`, `docs/design-overview.md`, `docs/architecture.md` (widget shell, skins). No CONTRIBUTING or ADRs found. `.impeccable/config.json` holds only one detector ignore for `lab/infopanel`.

Excluded: individual widget internals (`src/widgets/*` kinds, `primitives.tsx`, skins), studio editor chrome, `WindowControls`, server code.

Not reviewed: rendered output (no browser run), RTL (the kiosk is LTR-only), real glass/skin background colours behind text, `lib/island/*` logic beyond `system.ts`.

Conventions that settle taste here: dense, terse UI; kiosk is a passive display with optional touch; reduced motion is routed through `useReducedMotion` (a profile/URL/OS flag), which the code uses correctly everywhere I checked except the one listed below.
