# Design audit findings (consolidated ledger)

Branch `design/full-audit`. Consolidates the six per-surface audits (A kiosk, B studio editing, C studio flows, D desktop shell/settings/help, E widgets, F shared tokens; 169 raw findings) into 93 rows. Machine-readable twin: `findings.json`.

## Scope and method

- Scope: every surface the six audits cover (see "Not reviewed" for what they did not).
- Severity ladder and consolidation rules follow `.claude/skills/better-interface/SKILL.md` and `review-format.md`: HIGH = blocks a task, misleads, hides content/controls, data-loss risk or repeated systemic failure (escalation triggers are HIGH on sight); MEDIUM = harms comprehension/efficiency/consistency; LOW = isolated polish.
- Dedup: a finding caused by a shared token or primitive is owned by its F row (or the shared row where F has none) and the surface findings were merged in as extra locations; the same issue across surfaces with no shared cause became one row with all locations. `Sources` lists every original ID folded in.
- Batches: 1 tokens-colors, 2 accessibility, 3 layout-typography, 4 copy, 5 ui-motion, 0 bug (functional defects found along the way).
- `exportRisk` marks rows touching `widgets/core/theme.ts` or values mirrored into `lib/infopanel/gauges/vector.ts` (`THEME`: dark fg/muted/track, `STATE` ok/warn/crit, default accent `#34d399`); fix those with a paired `vector.ts` check.
- Spot-check: every HIGH was opened at its cited path:line (rows marked `checked`). Three were downgraded; several line citations had drifted (see the last section). Medium/low rows keep the source audit's evidence label (verified/inferred) and were not re-opened.

## Static-review caveat

All six audits are static: no dev server or browser was run, contrast ratios were computed from token values (not rendered over real backgrounds or images), and focus order, 320px/200% zoom, forced-colors, and screen-reader output were not observed. Rows whose evidence says "inferred" need a rendered or assistive-technology check before the fix is accepted.

## Not reviewed (collected from all six files)

- A: rendered output, RTL, real glass/skin background colours behind text, `lib/island/*` beyond `system.ts`; widget internals, studio editor chrome, `WindowControls`, server code. Not verified: browser walk (focus order, 320px, 200% zoom), screen-reader announcements.
- B: Add, Library, Gauges, Screens, Import, first-run, alerts flows (C), widget internals. Not verified: ruler legibility at low zoom, live tab/focus order, forced-colors, 320px/200%, the `ContextMenu`/`Popover` primitives' keyboard handling (`components/ui/context-menu.tsx`, `popover.tsx` not read), the eight Edit v3 fixture states visually.
- C: canvas/inspector editing (B), widget internals, `infopanel/edit/*`, gauge editor inspector and canvas internals. Not verified: contrast over images, 320px/200%, screen-reader output, focus return inside Base UI dialogs (assumed default). Typography/colour from token values only; motion beyond reduced-motion presence in `index.css` not reviewed.
- D: studio editor and widgets; `docs/architecture.md`; `settings/sections/touch.tsx`, `agents.tsx`, most of `server.tsx` (grep only); `help/search.ts`, `check.ts`, `build.ts`, `parse.ts`; the other 33 Help articles' copy. Not verified: sticky-bar overlap, scroller focus, reflow at 150% zoom in a 760px window, release rail height (need a WebView2 run).
- E: widget shell and skins (A, F); the six `better-*` domain skills were not loaded for this audit (rules applied from the better-interface summary); no keyboard/focus or screen-reader pass; no measured contrast; motion/reduced-motion; narrow widths beyond 2x2; `docs/design-overview.md` and `.impeccable/config.json` not read in depth.
- F: component-level layout of studio screens, per-widget internals, copy (better-writing not in scope); rendered appearance (glass over real page backgrounds, forced-colors, live `appearance: base-select` list inferred). Usage counts are greps, so approximate.
