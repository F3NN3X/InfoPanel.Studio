# Reviewer E: widget kinds (Widget QA page)

## Scope
Reviewed: every kind in `src/widgets/*.tsx` plus `core/primitives.tsx`, `core/views.tsx`, `core/theme.ts` as the widgets use them. Evidence: the default skin's 2x2 and 4x4 shots for all kinds (contact sheets of `.cache/qa-shots/baseline/default`); `_view-*` shots only via code; tui, nixie, retro and ink 2x2 shots for 12 risk widgets. Code read for empty/error paths in SensorValue, SystemOverview, StreamDeck, FpsMonitor, Notifications, Departures, SessionStats, MeterBridge, WaveLink.
Excluded: widget shell and skins (A, F); widget-level misuse of them is listed.
Project docs found: AGENTS.md, docs/TESTING.md. Not read in depth: `docs/design-overview.md`, `.impeccable/config.json`.
Not reviewed: the six `better-*` domain skills were not loaded, so their rules were applied from the better-interface summary only. Accessibility: no keyboard/focus or screen-reader pass. Colors: no measured contrast (token values not computed). Motion/reduced-motion. Narrow widths beyond 2x2. Findings marked `inferred` need a contrast or visual measurement.
