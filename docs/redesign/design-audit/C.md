# Design audit C: studio flows and dialogs

Branch `design/full-audit`. Static review; nothing was run in a browser. `verified` = the code proves it (or contrast computed from token values); `inferred` = needs a visual or assistive-tech check.

## Scope reviewed
- Dialogs: `studio/{reset-config,config-update,make-theme,page-icon,shortcuts,widget-picker}-dialog.tsx`, `studio/command-palette.tsx`, `studio/screens/delete-dialog.tsx`, `library/remove-item-dialog.tsx`, `gauges/unsaved-dialog.tsx`, `infopanel/{import/import-dialog,export-dialog,convert-dialog,remap-dialog}.tsx`, `studio/export-sheet.tsx`, `studio/first-run/first-run-page.tsx`, `library/profile-assets/drawer.tsx`, `studio/{pane-sheet,bottom-sheet}.tsx`.
- Flows: Add/Insert (`studio/add-*`, `insert-*`), Library (`library/`, `studio/media-library|media-field|background-library`), Gauges page (`gauges/gauges-page.tsx`), Screens (`studio/screens*`), Alerts editor (`studio/alerts-*`), Connections (`connections/`, `studio/connection-card`, `sources-panel`), Templates (`templates/`), shared `ui/{toast,segmented,popover,icon-button}.tsx`.
- Domain order followed: accessibility, layout, writing, typography, colors, ui.
- Excluded: canvas/inspector editing (reviewer B), widget internals, `infopanel/edit/*`, the gauge editor's inspector and canvas internals.
- Not verified: rendered contrast over images, 320px / 200% zoom, screen-reader output, focus return inside Base UI dialogs (assumed to follow Base UI defaults). Typography and colors reviewed from token values only. `better-ui` motion not reviewed beyond reduced-motion presence in `index.css`.
- Recon: `AGENTS.md`, `docs/TESTING.md`, `src/index.css` studio tokens, `src/settings/tokens.css`, `ui/*`. The project's dense, terse-copy conventions settled taste only; no finding rests on taste.
