Settings model
Every widget gets the same four tabs. A theme owns the look and the formats, and each widget follows it section by section.
Today: 34 standard rows on every widget, 334 own rows in 9 inspector categories plus one category per group name, and look keys alone layering from profile and dashboard. New: four task tabs, sections that follow the theme as a unit, and content preferences (units, thresholds, motion) that can be set once per profile.

Widget section
Follows · or Custom
Customize copies the theme values in and unlocks the rows. Use theme hides them again but keeps them stored.
Followable sections: Skin & graphics, Colors, Widget colors, Surface, Typography, Size & spacing, Border & glow, Custom CSS, Units & format, Thresholds, Motion.
Rows with no theme value (Tint from cover art, Background image) stay editable inside a following section.
Widget colors follow theme roles: Series 1–6, OK, Warning, Critical. A CPU colour is "Series 1" until customised.
Replaces styleMode (follow / custom / unset) and styleEnforce. Migration in SPEC §6.
