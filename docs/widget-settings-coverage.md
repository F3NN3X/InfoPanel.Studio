# Widget settings coverage

> A snapshot from 2026-10-15 (the settings audit in #9); its script was a one-off and isn't in the repo, so widgets
> and settings added since aren't in it. For the current state, `npm run audit:views` lists the options that change
> nothing in a view, into `.cache/view-options.md`.

Where each widget's own settings take effect. Generated by rendering every template through
the kiosk path (`placementContent`) at each grid span (cell 150, gap 8, fixture data) with the
default value and each alternative, and comparing the HTML. Look settings shared by every
widget (skin, surface, font, title, …) are in [widget-settings.md](widget-settings.md).

- **Takes effect at**: the spans where changing the setting changes the widget. Spans
  below the widget's minimum size are not tested.
- **Needs**: another setting it depends on (the inspector hides it otherwise), or the
  data it waits for. Visualiser and animation settings change what a canvas draws, which
  the HTML comparison does not see; they are marked *canvas*.
