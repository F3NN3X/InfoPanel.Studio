The ten small building blocks you place inside a panel.

:::generated panel-widgets.table

## Shared options

Every panel widget also has a label, sensor, unit, colour, size and placement, class names and custom CSS.

| In a… | Placement means |
|---|---|
| Stack | **Hug** (content size), **Fill** (share the free space) or **Fixed** (px) |
| Grid | Column and row span, and start cell |
| Overlay | Which band: Top, Middle or Bottom |

:::note
When a theme forces the global style, panel widget colours follow the theme too: fills take the accent.
:::
