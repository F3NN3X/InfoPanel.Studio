A color, gradient, image or video behind all zones.

| Type | Options |
|---|---|
| None | No background |
| Color | Any color |
| Gradient | **From**, **To** and **Angle** |
| Image | Fit (Cover, Contain, Stretch, Center, Tile), position and fill |
| Video | Video and Poster image, Loop, Muted, Speed (0.5× to 2×), fit (no Tile) |

Every type also has **Dim**, **Tint**, **Tint opacity** and **Blur** (in px), which keep text readable over busy pictures.

## Dashboard and profile

Set a background for all profiles in **Appearance**, then per profile choose **Inherit**, **Custom** or **None** in **Dashboard › Profile**.

:::note
Videos pause when the kiosk is hidden. With reduced motion on, only the poster frame shows.
:::
