A colour, gradient, image or video behind all zones.

| Type | Options |
|---|---|
| Color | Any colour or theme token |
| Gradient | Linear or radial, with stops |
| Image | URL or upload; fit (cover, contain, stretch, center, tile); position |
| Video | URL or upload; loops muted |

Every type also has **dim**, **tint** and **blur**, which keep text readable over busy pictures.

## Dashboard and profile

Set a background for all profiles, then per profile choose **Inherit**, **Custom** or **None**.

:::note
Videos pause when the kiosk is hidden. With reduced motion on, only the poster frame shows.
:::
