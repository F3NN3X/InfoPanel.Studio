One place for what you reuse: Themes, Styles, Panels, gauges, images, videos, fonts and imported canvases. Gauges are built and edited in their own view, **Gauges** on the rail.

Open **Library** on the rail. The sidebar lists the **Smart** collections and the collections by type; the header has search, Grid and Shelves, a **Used by** filter for one screen, **Canvas files** for the files the current screen uses (see [Assets and fonts](assets)) and **Add files…**, which opens the Import door (see [Importing and exporting](import)).

## Collections

Smart: All items, Recent, Unused, Large files, Duplicates and Suggested for theme. By type: Themes, Styles, Panels, Gauges, Media (Images, Videos, Backgrounds, Icons and SVG templates), Fonts, Components and InfoPanel profiles. Saved Themes and Styles sit beside the built-in ones.

## Components

A component is a piece of an InfoPanel profile you saved to reuse: a few items, a group, or an element such as a Row or Drives. Save one in the InfoPanel editor (see [InfoPanel editor](infopanel-editor)). **Components** lists them with a thumbnail of each. A component isn't a profile, so it doesn't appear under InfoPanel profiles or on the InfoPanel home page.

Drag a component onto the screen to get a canvas zone of its own, or onto a canvas zone to merge its items there. **Place on this page** does the first in the free cell that draws it largest. Each placement counts as a copy, so the component shows as used, and removing it from the Library never deletes a file a placed copy still draws.

## Themes and Styles

Select a Theme to see its colors, corners, background, widget style and the screens that use it. **Apply to…** puts it on All screens, this screen or this page (a page takes the widget style only). **Edit in Theme** applies it to All screens and opens Theme in an **Editing** state, where **Update ‹name›** saves the look back into it. A saved Theme can also be renamed, duplicated and deleted; a built-in palette can be applied and duplicated.

Select a Style to see its settings. **Apply to selection** gives them to the selected widgets, and **Update from selection** replaces them with the selected widget's own look. Saved Styles can be renamed, duplicated and deleted; a built-in Style can be applied and duplicated. All of these are one undo step.

## The right-click menu

Right-click an item. The first row depends on what it is: Set as background, Open in editor (a gauge opens in Gauges), Edit profile, Edit in Theme, Apply to selection, Add to screen, Show font or Add to canvas. Other rows can include Add to canvas, Duplicate, Optimise, Export .gauge.json, Export… and, on a canvas, Add to this page…. Edit profile opens the InfoPanel editor on the screen and page that use the profile, or, for a profile nothing uses yet, brings it in as a new screen and opens the editor there. The cards show the profile itself. Save one from the editor with **Save to Library**; Add to this page… puts it in a canvas zone on the current page. Every item has **Rename** and **Remove from library…** (`Delete`).

## Removing an item

**Remove from library…** asks for confirmation. The item leaves My library, and copies already placed stay where they are. Its file is deleted too, unless a screen, a canvas or another item still uses it. Confirm with **Remove**.

## Uploaded files not in My library

When older uploads aren't in My library, a banner says how many there are. Press **Review…** to list them, each with a thumbnail and its size. Tick files with **Select all**, **Select unused** or one by one, then press **Add to My library**, or **Delete…** to remove them for good. A file tagged **Used by a screen** can be added but not deleted.
