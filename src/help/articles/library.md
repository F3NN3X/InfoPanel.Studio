Everything you can reuse is here, yours and the built-in ones: Themes, skins, Styles, Panels, gauges, images, videos, fonts, components, InfoPanel profiles, screen templates, InfoPanel templates and Island looks. Gauges are built and edited in their own view, **Gauges** on the rail. The Theme page and the Add list still work as before; the Library is where you see and manage all of it in one place.

Open **Library** on the rail. The sidebar lists the **Smart** collections and the collections by type; the header has search, Grid and Shelves, a **Used by** filter for one screen, **Canvas files** for the files the current screen uses (see [Assets and fonts](assets)) and **Add files…**, which opens the Import door (see [Importing and exporting](import)).

## Collections

Smart: All items, Recent, Not used, Large files, Duplicates and Suggested for theme. By type: Themes, Skins, Styles, Panels, Gauges, Media (Images, Videos, Backgrounds, Icons and SVG templates), Fonts (with the Built-in fonts under it), Components, InfoPanel profiles, Screen templates, InfoPanel templates and Island looks. Your own items sit beside the built-in ones, and a built-in card is tagged **Built-in**.

## Every upload is in My library

Every image or video you upload is in My library, wherever you uploaded it: Add files, a background, or an image widget. Files uploaded before this, and any upload that no item held yet, are added when you open the Library, and a message says how many. Each keeps its stored file and is named after it, for example "Upload 1a2b3c4d.png"; rename it to whatever you like.

## Not used

**Not used** lists what no screen uses: nothing placed from it, and for a file, no background, widget or canvas showing it. In this collection, **Remove these files…** removes every image, video and SVG shown, after you confirm. Each file is checked again first, and one that a screen uses stays.

## Components

A component is a piece of a page you saved to reuse: a few items, a group, an element such as a Row or Drives, or on a screen's page widgets too. Save one in Edit with **Save to Library** on a screen's page (see [The studio](studio)) or on an InfoPanel profile (see [InfoPanel profiles in Edit](infopanel-editor)). **Components** lists them with a thumbnail of each. A component isn't a profile, so it doesn't appear under InfoPanel profiles or in Screens.

Drag a component onto the screen to get an InfoPanel group of its own, or onto an imported profile's page to merge its items there. **Place on this page** does the first in the free cell that draws it largest. Each placement counts as a copy, so the component shows as used, and removing it from the Library never deletes a file a placed copy still draws.

## Themes, skins and Styles

Select a Theme to see its colors, corners, background, widget style and the screens that use it. **Apply to…** puts it on All screens, this screen or this page (a page takes the widget style only). **Edit in Theme** applies it to All screens and opens Theme in an **Editing** state, where **Update ‹name›** saves the look back into it. A saved Theme can also be renamed, duplicated and deleted. The built-in palettes and the screen templates' looks can be applied and duplicated; a template look brings its background with it.

A skin is how every widget is drawn: its card, fonts, numerals and graphs. Select one to see it drawn, then **Apply to…** All screens, this screen or this page, the same as picking it in Theme › Start from. **Duplicate** saves a Theme of your own with the current colors and that skin.

Select a Style to see its settings. **Apply to selection** gives them to the selected widgets, and **Update from selection** replaces them with the selected widget's own look. Saved Styles can be renamed, duplicated and deleted; a built-in Style can be applied and duplicated. All of these are one undo step.

## Panels and screen templates

**Add to screen** places a panel in the first free spot. The built-in panels can be duplicated into a panel of your own; your saved panels can also be renamed and deleted. Panels placed earlier keep their own widgets either way.

A screen template is a ready-made screen. **New screen from this** opens the New screen page with that template picked, where you choose the size, colors and name. **Duplicate** skips the page: it adds a screen made from the template, named "‹template› copy", to Screens at once, using the sensors on this PC. There is no list of templates of your own, so the copy is a normal screen and the template stays as it is.

## InfoPanel templates, Island looks and built-in fonts

**InfoPanel templates** are the ready-made profiles the New InfoPanel profile page offers. **New InfoPanel profile from this** opens that page with the template picked.

**Island looks** change how the Dynamic Island is drawn: its shape, color, opacity, border, shadow and weight. **Apply to this screen** or **Apply to all screens** sets those and turns the island on; what it shows, its size, font, clock and alerts stay as they were. One undo step puts it back. You can still set each of these by hand under Alerts & Island.

**Built-in fonts** are the fonts every Typography picker offers. A card shows the font; Google fonts load when you look at them, and offline a system font stands in. They can't be applied from here: pick a font in the Typography settings. **Fonts** itself lists the font files you added.

## The right-click menu

Right-click an item. The first row depends on what it is: Set as background, Open in editor (a gauge opens in Gauges), Edit profile, Edit in Theme, Apply to selection, Add to screen, New screen from this, Show font or Add to canvas. An InfoPanel template offers New InfoPanel profile from this, and an Island look Apply to this screen. Other rows can include Add to canvas, Duplicate, Optimise, Export .gauge.json, Export… and, on a canvas, Add to this page…. Edit profile opens Edit on the screen and page that use the profile, or, for a profile nothing uses yet, brings it in as a new screen and opens it there. The cards show the profile itself. Save one from Edit with **Save to Library**; Add to this page… puts it on the current page. Your own items have **Rename** and **Remove from library…** (`Delete`); a saved panel has **Delete**. Built-in items have neither. Skins, screen templates, InfoPanel templates, Island looks and built-in fonts don't drag onto the canvas: use their buttons.

## Removing an item

**Remove from library…** asks for confirmation. The item leaves My library, and copies already placed stay where they are. Its file is deleted too, unless a screen, a canvas or another item still uses it. Confirm with **Remove**.

An image, video or SVG that a screen still uses can't be removed: a message says so and the item stays. Take it off the screen first, for example by clearing the background or the image widget.

## Deleting several at once

Press **Select** in the header and tick cards, or Ctrl-click to add one and Shift-click for a range. The header shows how many are selected, with **Select all**, **Clear** and **Delete…**. Delete on a ticked card does the same. The confirm lists what goes and what stays, and why. Built-in items stay, since they ship with the app. An image, video or SVG that a screen uses stays, and each file is checked again just before it goes. Saved Themes, Styles and panels go in one undo step.
