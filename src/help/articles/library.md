Everything you can reuse is here, yours and the built-in ones: Themes, skins, Styles, Panels, gauges, images, videos, fonts, components, InfoPanel profiles and screen templates. Gauges are built and edited in their own view, **Gauges** on the rail. The Theme page and the Add list still work as before; the Library is where you see and manage all of it in one place.

Open **Library** on the rail. The sidebar lists the **Smart** collections and the collections by type; the header has search, Grid and Shelves, a **Used by** filter for one screen, **Canvas files** for the files the current screen uses (see [Assets and fonts](assets)) and **Add files…**, which opens the Import door (see [Importing and exporting](import)).

## Collections

Smart: All items, Recent, Not used, Large files, Duplicates and Suggested for theme. By type: Themes, Skins, Styles, Panels, Gauges, Media (Images, Videos, Backgrounds, Icons and SVG templates), Fonts, Components, InfoPanel profiles and Screen templates. Your own items sit beside the built-in ones, and a built-in card is tagged **Built-in**.

## Every upload is in My library

Every image or video you upload is in My library, wherever you uploaded it: Add files, a background, or an image widget. Files uploaded before this, and any upload that no item held yet, are added when you open the Library, and a message says how many. Each keeps its stored file and is named after it, for example "Upload 1a2b3c4d.png"; rename it to whatever you like.

## Not used

**Not used** lists what no screen uses: nothing placed from it, and for a file, no background, widget or canvas showing it. In this collection, **Remove these files…** removes every image, video and SVG shown, after you confirm. Each file is checked again first, and one that a screen uses stays.

## Components

A component is a piece of an InfoPanel profile you saved to reuse: a few items, a group, or an element such as a Row or Drives. Save one in Edit on an InfoPanel profile (see [InfoPanel editor](infopanel-editor)). **Components** lists them with a thumbnail of each. A component isn't a profile, so it doesn't appear under InfoPanel profiles or in Screens.

Drag a component onto the screen to get a canvas zone of its own, or onto a canvas zone to merge its items there. **Place on this page** does the first in the free cell that draws it largest. Each placement counts as a copy, so the component shows as used, and removing it from the Library never deletes a file a placed copy still draws.

## Themes, skins and Styles

Select a Theme to see its colors, corners, background, widget style and the screens that use it. **Apply to…** puts it on All screens, this screen or this page (a page takes the widget style only). **Edit in Theme** applies it to All screens and opens Theme in an **Editing** state, where **Update ‹name›** saves the look back into it. A saved Theme can also be renamed, duplicated and deleted. The built-in palettes and the screen templates' looks can be applied and duplicated; a template look brings its background with it.

A skin is how every widget is drawn: its card, fonts, numerals and graphs. Select one to see it drawn, then **Apply to…** All screens, this screen or this page, the same as picking it in Theme › Start from. **Duplicate** saves a Theme of your own with the current colors and that skin.

Select a Style to see its settings. **Apply to selection** gives them to the selected widgets, and **Update from selection** replaces them with the selected widget's own look. Saved Styles can be renamed, duplicated and deleted; a built-in Style can be applied and duplicated. All of these are one undo step.

## Panels and screen templates

**Add to screen** places a panel in the first free spot. The built-in panels can be duplicated into a panel of your own; your saved panels can also be renamed and deleted. Panels placed earlier keep their own widgets either way.

A screen template is a ready-made screen. **New screen from this** opens the New screen page with that template picked, where you choose the size, colors and name.

## The right-click menu

Right-click an item. The first row depends on what it is: Set as background, Open in editor (a gauge opens in Gauges), Edit profile, Edit in Theme, Apply to selection, Add to screen, New screen from this, Show font or Add to canvas. Other rows can include Add to canvas, Duplicate, Optimise, Export .gauge.json, Export… and, on a canvas, Add to this page…. Edit profile opens Edit on the screen and page that use the profile, or, for a profile nothing uses yet, brings it in as a new screen and opens it there. The cards show the profile itself. Save one from Edit with **Save to Library**; Add to this page… puts it in a canvas zone on the current page. Your own items have **Rename** and **Remove from library…** (`Delete`); a saved panel has **Delete**. Built-in items have neither.

## Removing an item

**Remove from library…** asks for confirmation. The item leaves My library, and copies already placed stay where they are. Its file is deleted too, unless a screen, a canvas or another item still uses it. Confirm with **Remove**.

An image, video or SVG that a screen still uses can't be removed: a message says so and the item stays. Take it off the screen first, for example by clearing the background or the image widget.
