One place for the files you reuse: images, videos, fonts, gauges, saved panels and imported canvases.

Open **Library** on the left rail. The header has two tabs: **My library**, for everything you keep across profiles, and **Profile assets**, for the files the current profile uses (see [Assets and fonts](assets)). Search with "Search everything…", switch between Grid and Shelves, and use **Import profile** or **Upload** to add files.

## Collections

All items, Recent, Unused, Large files, Duplicates, Suggested for theme, Images, Videos, Backgrounds, Icons, SVG templates, Fonts, Gauges & bars, Saved panels, Style presets and Imported canvases.

## The right-click menu

Right-click an item. The first row depends on what it is: Set as background, Open in editor, Open canvas, Apply to selection, Add to profile, Show font or Add to canvas. Other rows can include Add to canvas, Duplicate, Optimise, Export .gauge.json, Export… and Re-import…. Every item has **Rename** and **Remove from library…** (`Delete`).

## Removing an item

**Remove from library…** asks for confirmation. The item leaves My library, and copies already placed stay where they are. Its file is deleted too, unless a profile, a canvas or another item still uses it. Confirm with **Remove**.

## Uploaded files not in My library

When older uploads aren't in My library, a banner says how many there are. Press **Review…** to list them, each with a thumbnail and its size. Tick files with **Select all**, **Select unused** or one by one, then press **Add to My library**, or **Delete…** to remove them for good. A file tagged **Used by a profile** can be added but not deleted.
