Manage the images, videos and fonts an imported profile carries.

## Files

Each file shows a preview, its real type and pixel size, byte size and how many items use it. URL and absolute-path images are listed separately.

- **Add files** — duplicates are merged by content.
- **Use for selection** — assign to the selected items.
- **Replace…** — every use follows the new file.
- **Remove** — clears its uses.

## Cleanup

Finds unused files, identical copies (merged), images larger than drawn, files over 1 MB and missing files. **Downscale** shrinks an image to its drawn size.

## Optimise images

Re-encodes still images (same type or WebP) with a quality and size cap. A file is only replaced when it gets at least 5 % smaller. One undo step.

## Replace by name

Pick a set of files; they are matched to the profile's files by name. You see matches, identical, unmatched and ambiguous before anything changes.

## Fonts

For each font the profile asks for, see the face that will be drawn and where it came from. Add fonts (ttf, otf, ttc, zip) or get them from Fontsource or Font Squirrel. Each font shows its licence and whether it may be shared.

:::warn
Before sharing an exported profile, check the fonts marked **check** or **do not share**.
:::
