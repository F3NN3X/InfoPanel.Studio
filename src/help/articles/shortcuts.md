Shortcuts never fire while you are typing in a field.

## In the studio

:::generated shortcuts.keys

`Ctrl+K` opens the command palette in the studio, and the search box in Settings.

The **InfoPanel editor** group works in Edit on an InfoPanel profile or a canvas zone's items.

## Settings window

:::keys
Ctrl+K — Search settings
Ctrl + — Zoom in
Ctrl − — Zoom out
Ctrl 0 — Reset zoom
:::
